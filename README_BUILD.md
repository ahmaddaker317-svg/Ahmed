# ADT Stock V169 — GitHub Ready

هذه النسخة مبنية على مشروع V168 مع إضافة نظام صلاحيات المبيعات اليومية وتقييد حذف النواقص، مع الحفاظ على مشروع Android وFirebase والحزمة `com.adt.pro`.

## الجديد في V169

- زر **المبيعات اليومية** يظهر لجميع الحسابات في الصفحة الرئيسية.
- العضو لا يستطيع فتح/استخدام المبيعات اليومية إلا بعد تفعيل صلاحية **المبيعات اليومية (عرض وإضافة)** له من المدير الرئيسي.
- العضو المسموح له بالمبيعات يستطيع عرض الإجمالي والسجل وإضافة مبيعات جديدة.
- **تصفية دورة المبيعات** تظل للمدير الرئيسي فقط، ولا تظهر للعضو.
- كارت **فريقي والصلاحيات** مخفي من الصفحة الرئيسية عند الأعضاء والمدير المساعد، ويظهر للمدير الرئيسي فقط.
- صلاحية النواقص للعضو أصبحت **عرض وإضافة النواقص**.
- العضو المسموح له بالنواقص يمكنه إضافة الأصناف الناقصة، لكن زر **تم التوفير/الحذف** لا يظهر له.
- حذف صنف من النواقص محمي أيضاً في Supabase ومتاح للمدير الرئيسي فقط.
- كل تعديلات V168 السابقة ما زالت موجودة: تسجيل الدخول الموحد، تحسين الجرد، المبيعات اليومية، ترتيب الصفحة الرئيسية، الشعار الشفاف، Firebase والإشعارات.
