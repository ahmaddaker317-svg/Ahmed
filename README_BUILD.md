# ADT Pro V143 — GitHub Ready

مبنية مباشرة على V138 مع تعديل صلاحيات واجهة المنتجات فقط.

## التعديل
- إضافة صنف جديد: المدير الرئيسي فقط.
- المدير الرئيسي يرى نموذج الصنف الكامل.
- العضو/المدير المساعد لا يرى زر تعديل المنتج إلا عند تفعيل صلاحية **تغيير سعر البيع** له.
- عند فتح التعديل لعضو/مدير مساعد يظهر **سعر البيع فقط**؛ لا يظهر الاسم، سعر الشراء، التعبئة/عدد القطع، أو المورد.
- حذف الصنف: المدير الرئيسي فقط.
- سعر الشراء وعدد القطع وباقي حقول الصنف محمية Server-side من تعديل غير المدير الرئيسي.
- لم يتم تغيير Firebase أو تسجيل الدخول أو الجرد أو الديون أو النواقص أو نظام المزامنة.
