# ADT Pro v132 Android + Firebase FCM

هذا المشروع مبني خصيصًا لـ ADT Pro ويحتوي على:

- Package: `com.adt.pro`
- Firebase Cloud Messaging (FCM)
- تمرير FCM Token تلقائيًا إلى JavaScript عبر:
  - `window.ADT_registerPushToken(token)`
  - `window.Android.getFcmToken()`
- حفظ التوكن محليًا وإعادة تمريره عند فتح التطبيق
- استقبال الإشعارات خارج التطبيق وفي الخلفية
- إعادة ربط رمز FCM بالخادم من Android نفسه إذا تغيّر والتطبيق مغلق
- إعادة محاولة مزامنة الرمز تلقائيًا عند عودة الإنترنت
- قناة إشعارات عالية الأهمية مع صوت واهتزاز
- زر مباشر لإعدادات إشعارات الهاتف من القائمة الجانبية
- كود Supabase Edge Function الخاص بإرسال إشعارات الأسعار داخل المشروع
- طلب إذن الإشعارات على Android 13+
- خلفية WebView داكنة `#070A12`
- لا يوجد Pull-to-Refresh
- صفحة انقطاع إنترنت داكنة بدون إظهار رابط الموقع
- واجهة التطبيق المدمجة: `app/src/main/assets/index.html`
- فتح روابط واتساب والدعم خارج التطبيق مباشرة
- إنشاء ملفات كشف الحساب PDF ثم فتح واجهة المشاركة الأصلية
- تصدير واستيراد جميع المنتجات والأسعار بصيغة JSON
- اختيار مكان حفظ ملفات JSON من مدير ملفات Android
- ملف `google-services.json` مضمّن لمشروع Firebase `adt-pro0`
- إصلاح ظهور نتائج بحث المنتجات داخل فاتورة المبيعات
- إدارة اسم المحل وعنوانه من نافذة بيانات المستخدم والمتجر
- عرض «فاتورة مبيعات» بخط بارز في منتصف رأس الفاتورة
- عرض اسم المحل وعنوانه في منتصف شريط بيانات الفاتورة بين المستخدم والتاريخ
- مزامنة اسم كل مستخدم مع جميع أجهزة الفريق عبر Supabase
- إخفاء واجهات الجرد والديون والنواقص عن العضو حتى يسمح بها المدير
- فصل نتائج بحث المنتجات: نتيجة سريعة للمدير وبطاقات مفلترة للأعضاء
- ضمان ظهور تنبيه «لا يوجد جرد» فوق نافذة آخر جرد
- قفل تعديل سعر الشراء على مدير الفريق الرئيسي فقط داخل الواجهة وقاعدة البيانات
- حماية سعر الشراء من التغيير عند الاستيراد بواسطة المدير المساعد أو الأعضاء
- إعادة إرسال تحديثات الأسعار عبر Edge Function مع بديل Android تلقائي
- إصدار Android: `versionCode 132` و`versionName 1.32.0`

## البناء بدون Android Studio
المشروع يحتوي على GitHub Actions في:
`.github/workflows/main.yml`

ارفع محتويات المشروع إلى مستودع GitHub ثم افتح Actions وشغّل:
`Build ADT Pro APK`

بعد اكتمال البناء حمّل Artifact باسم:
`ADT-Pro-v132-APK`

## اختبار التوكن
بعد تثبيت التطبيق، افتحه وسجّل الدخول للفريق، ثم في Supabase نفّذ:

```sql
select team_id,user_id,platform,enabled,length(token) token_length,updated_at
from public.adt_push_tokens
order by updated_at desc;
```

يجب أن يظهر صف للجهاز بدل `No rows returned`.

## قاعدة البيانات

المشروع لا يغيّر بيانات Supabase أثناء البناء. شغّل `V132_PUSH_NOTIFICATIONS.sql`
مرة واحدة لتسجيل أجهزة الإشعارات، ثم انشر الدالة الموجودة في
`supabase/functions/adt-send-price-push` واضبط أسرار Firebase وفق `V132_PUSH_SETUP.md`.
وشغّل `V131_PRIMARY_MANAGER_BUY_PRICE.sql`
مرة واحدة لقفل تعديل سعر الشراء على مدير الفريق الرئيسي فقط، ثم شغّل `V130_MEMBER_NAME_AND_ACCESS.sql`
مرة واحدة لتفعيل مزامنة أسماء المستخدمين والتأكد من أعمدة صلاحيات الجرد والديون والنواقص.
وشغّل `V128_STORE_PROFILE.sql`
مرة واحدة في Supabase SQL Editor لتفعيل حفظ اسم المحل وعنوانه لجميع أجهزة الفريق.
وإذا لم يكن تحديث صلاحيات V92 مطبقاً، شغّل `V92_PERMISSIONS_SYNC.sql` مرة واحدة.
