ADT Pro v132
============

1) ربط FCM token بالفريق من طبقة Android وليس من WebView فقط.
2) مزامنة token الجديد حتى إذا تغيّر والتطبيق مغلق.
3) إعادة المحاولة تلقائياً عند توفر الإنترنت باستخدام JobScheduler.
4) قناة إشعارات عالية الأهمية بصوت واهتزاز وظهور على شاشة القفل.
5) إعدادات FCM الافتراضية لرسائل الخلفية.
6) تعطيل token عند مغادرة الفريق أو تسجيل الخروج.
7) زر «إعدادات إشعارات الهاتف» في القائمة الجانبية.
8) SQL لتسجيل وإلغاء رموز الأجهزة.
9) مصدر Supabase Edge Function للإرسال عبر FCM HTTP v1.
10) استمرار قفل سعر الشراء على مدير الفريق الرئيسي فقط.

ملاحظة V136: تعليمات Push الجديدة المذكورة سابقاً في V132 أُلغيت؛ V136 يستخدم مسار الإشعارات القديم الشغال من V93.
